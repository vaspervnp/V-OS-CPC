V-OS · Πρότυπα interface για Amstrad CPC 6128

Επιλογή: το Desktop (A) ως αρχική οθόνη, με τον Launcher (B) και τον Commander (C) ως εναλλακτικές όψεις του ίδιου shell. Όλα σχεδιάζονται με τους πραγματικούς περιορισμούς του CPC: overscan 384×272, παλέτα 27 χρωμάτων hardware, 4 inks σε mode 1 και 16 σε mode 0, γραμματοσειρά 8×8. Κάθε οθόνη λειτουργεί: κάνε κλικ πάνω της και δοκίμασε ποντίκι και πλήκτρα.

Τα σχέδια ζωγραφίζονται pixel-pixel σε framebuffer 384×272 με τα χρώματα του Gate Array.

Επιλέχθηκε ο συνδυασμός A + B + C: ένα shell με κοινή μηχανή μενού, εστίασης και αρχείων, και τρεις όψεις που αλλάζουν mode και παλέτα στο VSYNC. Τα προγράμματα χρήστη ζητούν το mode που θέλουν μέσω του API. Το D μένει ως πιθανή μελλοντική όψη για τον editor blocks. Το κείμενο απαιτήσεων βρίσκεται στο docs/REQUIREMENTS.md του repo.
