# 5. Studio: προγράμματα με blocks

Το STUDIO είναι editor blocks τύπου Scratch που τρέχει πάνω στον ίδιο τον CPC.

- Φτιάχνεις αντικείμενα (sprites) και scripts από blocks.
- Το πρόγραμμα τρέχει αμέσως με CONTROL+R.
- Γίνεται κανονικό πρόγραμμα του V-OS (`.VBN`) που ξεκινά και από τον Launcher.

## Η οθόνη

Το Studio χρησιμοποιεί «μικτή» οθόνη, με δύο ζώνες:

- **Πάνω, σε mode 0 (16 χρώματα):**
  - **αριστερά, η σκηνή** σε μισό μέγεθος
  - **δεξιά, το πάνελ ΑΝΤΙΚΕΙΜΕΝΑ:** τα αντικείμενα με το χρώμα και τη θέση τους, το μέγεθος του επιλεγμένου (W, H), το φόντο και το mode του προγράμματος (π.χ. `ΣΚΗΝΗ 2 M1`), και το όνομα του αρχείου
- **Κάτω, σε mode 1:**
  - **αριστερά, η παλέτα** με τα blocks μιας κατηγορίας (`< ΓΕΓΟΝΟΤΑ >`)
  - **δεξιά, το script**, μία γραμμή για κάθε block
  - **στο τέλος, η γραμμή κατάστασης**, με τα πλήκτρα που ισχύουν εκεί που βρίσκεσαι

Το **TAB** περνά από το script στην παλέτα, μετά στη σκηνή, και πίσω στο script.

## Μενού

| STUDIO | | ΕΠΕΞΕΡΓΑΣΙΑ |
|---|---|---|
| ΝΕΟ | ^N | ΣΒΗΣΕ ΓΡΑΜΜΗ |
| ΑΝΟΙΓΜΑ (`.VBS`) | ^O | + ΑΝΤΙΚΕΙΜΕΝΟ (ως 6) |
| ΑΠΟΘΗΚΕΥΣΗ | ^S | − ΑΝΤΙΚΕΙΜΕΝΟ |
| ΑΠΟΘ. ΩΣ | | ΦΟΝΤΟ (το χρώμα της σκηνής) |
| ΕΚΤΕΛΕΣΗ | ^R | MODE ΟΘΟΝΗΣ (0 ή 1) |
| ΣΤΟ ΠΑΡΑΣΚΗΝΙΟ | | ΓΛΩΣΣΑ ΚΕΙΜΕΝ. (^T) |
| ΕΠΙΣΤΡΟΦΗ | ^Q | |

- **ΕΚΤΕΛΕΣΗ (^R):** αποθηκεύει το `ΟΝΟΜΑ.VBS`, γράφει το `ΟΝΟΜΑ.VBN` και το τρέχει. Το πρόγραμμα σταματά από το μενού του (ΠΡΟΓΡΑΜΜΑ > ΤΕΛΟΣ, ^Q), και τότε το Studio ξαναξεκινά με το ίδιο πρόγραμμα ανοιχτό.
- **ΣΤΟ ΠΑΡΑΣΚΗΝΙΟ:** ρωτά αν το πρόγραμμα θα συνεχίζει να τρέχει όταν είναι πίσω από άλλο ή πίσω από μια όψη, ή θα παγώνει, που είναι η προεπιλογή.
- **MODE ΟΘΟΝΗΣ:**
  - **Mode 0:** 16 χρώματα, πλάτος 192 pixels.
  - **Mode 1:** 4 χρώματα (πένες 0–3), πλάτος 384 pixels, και περισσότερο κείμενο.

## Η παλέτα

Τα ←/→ αλλάζουν κατηγορία, τα ↑/↓ διαλέγουν block, και το RETURN το προσθέτει κάτω από τη γραμμή του script. Ένα κλικ σε block της παλέτας κάνει το ίδιο.

Ένα block που ανοίγει (ΓΙΑ ΠΑΝΤΑ, ΕΠΑΝΑΛΑΒΕ, ΑΝ) μπαίνει μαζί με το ΤΕΛΟΣ του, και σβήνεται μαζί του. Ένα block με κείμενο ζητά το κείμενο αμέσως.

## Το script

| Πλήκτρο | Τι κάνει |
|---|---|
| ↑/↓ | γραμμή |
| ←/→ | πεδίο της γραμμής (τα πεδία είναι οι τιμές μέσα στο block) |
| RETURN | χωρίς επιλεγμένο πεδίο: προσθέτει το block της παλέτας. Σε πεδίο κειμένου: αλλαγή κειμένου. Σε πεδίο πλήκτρου: περιμένει να πατήσεις το πλήκτρο |
| CLR | σβήνει τη γραμμή |
| DEL | σβήνει το τελευταίο ψηφίο ενός αριθμού |
| ποντίκι | κλικ σε πεδίο: το επιλέγει. Δεύτερο κλικ: αλλάζει το είδος του |

Το πρόγραμμα είναι μια λίστα από γραμμές:

- Κάθε `ΟΤΑΝ …` ξεκινά ένα script, για ένα αντικείμενο ή για τη σκηνή. Το script φτάνει ως το επόμενο `ΟΤΑΝ`.
- Η εσοχή βγαίνει μόνη της από τα blocks που ανοίγουν και κλείνουν.
- Γραμμές πριν από το πρώτο `ΟΤΑΝ` αγνοούνται.
- Ό,τι μένει ανοιχτό κλείνει στο τέλος του script.

### Τι γράφεται σε ένα πεδίο

Η γραμμή κατάστασης λέει κάθε φορά τι δέχεται το πεδίο.

**Πεδίο τιμής:**

| Πλήκτρο | Τιμή |
|---|---|
| 0–9, − | αριθμός, ακέραιος από −32768 ως 32767 |
| A–H | μεταβλητή. Το ίδιο γράμμα ξανά: A1, A2 … A15, και πάλι A |
| X, Y | η θέση του αντικειμένου του script |
| R και ψηφία | ΤΥΧΑΙΟ: ένας αριθμός από 1 ως το n |
| K και πλήκτρο | ΠΛΗΚΤΡΟ: 1 όσο είναι πατημένο, αλλιώς 0 |
| T και ψηφίο | ΑΓΓΙΖΕΙ: 1 όταν το αντικείμενο αγγίζει το αντικείμενο n |
| Z | ΣΤΗΝ ΑΚΡΗ: 1 όταν το αντικείμενο είναι στην άκρη της σκηνής |
| P | ΚΟΥΜΠΙ: ο αριθμός του τελευταίου κουμπιού που πατήθηκε |
| U | ΚΟΣΤΟΥΜΙ: ο αριθμός του κοστουμιού του αντικειμένου (0: χωρίς κοστούμι) |

**Άλλα είδη πεδίου:**

- **Μεταβλητή:** A–H και πάλι το ίδιο γράμμα για A1…A15.
- **Σύγκριση:** `<`, `=`, `>`. Το SPACE δίνει «καμία», και τότε το ΑΝ ελέγχει μόνο αν η πρώτη τιμή δεν είναι 0.
- **Αντικείμενο** (στα `ΟΤΑΝ`): 0 η σκηνή, 1–6 ένα αντικείμενο.
- **Πλήκτρο** (στο `ΟΤΑΝ ΠΛΗΚΤΡΟ`): RETURN και μετά το πλήκτρο.
- **Κείμενο:** RETURN, και γράφεις ως 14 χαρακτήρες.
- **Ομάδα μεταβλητών** (SAVE/LOAD VARS): A–H προχωρά στην επόμενη οκτάδα (A-H, A1-H1 … A15-H15), και το SPACE δίνει ΟΛΕΣ.

Τα γράμματα διαβάζονται ως πλήκτρα, οπότε δουλεύουν και με το ελληνικό πληκτρολόγιο.

## Η σκηνή και τα αντικείμενα

| Πλήκτρο | Τι κάνει |
|---|---|
| βελάκια | μετακινεί το επιλεγμένο αντικείμενο |
| 1–6 | επιλογή αντικειμένου |
| C | επόμενο χρώμα |
| W, H | πλάτος, ύψος |
| K | ποιο κοστούμι φορά (κανένα, 1, 2, …) |
| E | σχεδίαση του κοστουμιού του (νέο, αν δεν έχει) |
| κλικ στη σκηνή | βάζει εκεί το αντικείμενο |

Ένα αντικείμενο χωρίς κοστούμι είναι ένα χρωματιστό ορθογώνιο.

### Κοστούμια

Το **E** ανοίγει τον επεξεργαστή κοστουμιών στη θέση της σκηνής. Έχει πλέγμα 16×16 και από κάτω τις 16 πένες.

| Πλήκτρο | Τι κάνει |
|---|---|
| βελάκια | κελί |
| SPACE, RETURN | βάφει το κελί |
| 0–9, A–F | πένα |
| `.` | διάφανο |
| E, TAB | τέλος |
| κλικ | σε κελί: βάφει. Στη σειρά των πενών: επιλογή πένας |

Ένα πρόγραμμα έχει ως 8 κοστούμια, κοινά για όλα τα αντικείμενα. Το μέγεθος ενός αντικειμένου με κοστούμι είναι 16×16. Στη σκηνή, το x στρογγυλεύεται σε ολόκληρο byte (2 pixels σε mode 0, 4 σε mode 1).

## Όλα τα blocks

Στη στήλη «Block», τα πεδία φαίνονται όπως στο script.

### ΓΕΓΟΝΟΤΑ

| Block | Τι κάνει |
|---|---|
| ΟΤΑΝ ΞΕΚΙΝΑ *αντικ.* | το script ξεκινά μαζί με το πρόγραμμα |
| ΟΤΑΝ ΠΛΗΚΤΡΟ *πλήκτρο* *αντικ.* | ξεκινά όταν πατηθεί το πλήκτρο |
| ΟΤΑΝ ΚΛΙΚ *αντικ.* | ξεκινά με κλικ στο αντικείμενο (ή στη σκηνή) |
| ΟΤΑΝ ΛΑΒΕΙ *n* *αντικ.* | ξεκινά όταν σταλεί το μήνυμα n |
| ΣΤΕΙΛΕ *n* | στέλνει το μήνυμα n (το n μπορεί να είναι και μεταβλητή) |

> Ένα μήνυμα ξεκινά **από την αρχή** κάθε script που το περιμένει, ακόμα κι αν έτρεχε ήδη. Γι' αυτό ένα script δεν πρέπει να στέλνει μήνυμα στον εαυτό του.

### ΕΛΕΓΧΟΣ

| Block | Τι κάνει |
|---|---|
| ΓΙΑ ΠΑΝΤΑ … ΤΕΛΟΣ | επαναλαμβάνει για πάντα |
| ΕΠΑΝΑΛΑΒΕ *n* … ΤΕΛΟΣ | n φορές |
| ΑΝ *a* *σύγκριση* *b* … [ΑΛΛΙΩΣ …] ΤΕΛΟΣ | εκτελεί τις γραμμές μόνο αν ισχύει η σύγκριση |
| ΠΕΡΙΜΕΝΕ *n* | περιμένει n frames (50 = ένα δευτερόλεπτο) |
| ΠΕΡΙΜΕΝΕ ΩΣ *a* *σύγκριση* *b* | περιμένει ώσπου να ισχύσει η σύγκριση |
| ΣΤΑΜΑΤΑ | τελειώνει αυτό το script |

### ΚΙΝΗΣΗ

| Block | Τι κάνει |
|---|---|
| ΠΗΓΑΙΝΕ *x* *y* | το αντικείμενο πάει στο x, y |
| ΑΛΛΑΞΕ X *n*, ΑΛΛΑΞΕ Y *n* | μετακινεί κατά n |
| ΤΑΧΥΤΗΤΑ *vx* *vy* | ορίζει την ταχύτητά του |
| ΚΙΝΗΣΟΥ | ένα βήμα με την ταχύτητά του |
| ΑΝΑΠΗΔΗΣΕ | στην άκρη της σκηνής, αντιστρέφει την ταχύτητα |

### ΕΜΦΑΝ./ΗΧΟΣ

| Block | Τι κάνει |
|---|---|
| ΧΡΩΜΑ *n* | η πένα του ορθογωνίου |
| ΚΟΣΤΟΥΜΙ *n* | φορά το κοστούμι n (1–8. Το 0 δεν αλλάζει τίποτα) |
| ΕΠΟΜΕΝΟ ΚΟΣΤΟΥΜΙ | το επόμενο, και μετά το τελευταίο πάλι το πρώτο |
| ΕΜΦΑΝΙΣΟΥ, ΚΡΥΨΟΥ | |
| ΓΡΑΨΕ *τιμή* ΣΤΟ *x* *y* | τυπώνει έναν αριθμό |
| ΣΤΥΛ *n* | το στυλ του ΓΡΑΨΕ και του ΚΕΙΜΕΝΟ που ακολουθούν: 1 έντονα, 2 πλάγια, 4 υπογράμμιση, και αθροισμένα (7: όλα), 0 απλά |
| ΝΟΤΑ *n* ΓΙΑ *frames* | παίζει νότα (αριθμός MIDI: 60 = ντο, 69 = λα 440 Hz) και περιμένει να τελειώσει |
| ΜΟΥΣΙΚΗ *"όνομα"* | παίζει το τραγούδι *όνομα*`.MUS` από τη δισκέτα του προγράμματος, πίσω από αυτό, με το πρόγραμμα MUSIC (στο A: ή στο B:). Συνεχίζει και μετά το τέλος του προγράμματος, ως το STOP του MUSIC (F6). Χρειάζεται επέκταση μνήμης· χωρίς αυτήν βγαίνει «ΚΛΕΙΣΤΕ ΠΡΩΤΑ ΑΛΛΟ ΠΡΟΓΡΑΜΜΑ». Ένα όνομα που δεν υπάρχει (ή κενό) σταματά τη μουσική |

### ΜΕΤΑΒΛΗΤΕΣ

| Block | Τι κάνει |
|---|---|
| ΘΕΣΕ *μεταβλητή* ΣΕ *τιμή* | |
| ΑΛΛΑΞΕ *μεταβλητή* ΚΑΤΑ *τιμή* | πρόσθεση |
| ΜΕΙΩΣΕ *μεταβλητή* ΚΑΤΑ *τιμή* | αφαίρεση |
| ΠΟΛΛΑΠΛΑΣΙΑΣΕ *μεταβλητή* ΕΠΙ *τιμή* | |
| ΔΙΑΙΡΕΣΕ *μεταβλητή* ΔΙΑ *τιμή* | ακέραια διαίρεση |
| ΥΠΟΛΟΙΠΟ *μεταβλητή* ΔΙΑ *τιμή* | το υπόλοιπο της διαίρεσης |
| ΑΠΟΘΗΚΕΥΣΕ *ομάδα* ΣΤΟ *"όνομα"* | γράφει τις μεταβλητές σε αρχείο κειμένου (δες παρακάτω) |
| ΦΟΡΤΩΣΕ *ομάδα* ΑΠΟ *"όνομα"* | τις διαβάζει πίσω |

### ΠΑΡΑΘΥΡΑ

| Block | Τι κάνει |
|---|---|
| ΠΑΡΑΘΥΡΟ *"τίτλος"* *πλάτος* *ύψος* | παράθυρο στη μέση της σκηνής, όπως οι διάλογοι του V-OS. Ένα νέο παράθυρο παίρνει τη θέση του προηγούμενου και των κουμπιών του |
| ΚΟΥΜΠΙ *"κείμενο"* ΣΤΟ *x* *y* | κουμπί του συστήματος. Πατιέται με κλικ ή με TAB και RETURN. Αριθμείται από το 0, με τη σειρά που εμφανίζονται |
| ΟΤΑΝ ΚΟΥΜΠΙ *αντικ.* | ξεκινά όταν πατηθεί οποιοδήποτε κουμπί. Η τιμή ΚΟΥΜΠΙ (P) λέει ποιο |
| ΚΕΙΜΕΝΟ *"κείμενο"* ΣΤΟ *x* *y* | γράφει κείμενο |
| ΕΤΙΚΕΤΑ *κουμπί* ΣΕ *"κείμενο"* | αλλάζει το κείμενο ενός κουμπιού |

Με ανοιχτό παράθυρο, τα ΚΕΙΜΕΝΟ, ΚΟΥΜΠΙ και ΓΡΑΨΕ μετρούν από την πάνω αριστερή γωνία του εσωτερικού του. Το παράθυρο σέρνεται από τον τίτλο του, μαζί με τα κουμπιά του.

## Μεταβλητές

Υπάρχουν 128 μεταβλητές, κοινές για όλα τα scripts, με ονόματα A–H, A1–H1, …, A15–H15. Στην αρχή όλες είναι 0, και κρατούν ακέραιους από −32768 ως 32767.

### Αποθήκευση και επαναφορά (SAVE VARS, LOAD VARS)

- `ΑΠΟΘΗΚΕΥΣΕ ΟΛΕΣ ΣΤΟ "GAME"` γράφει και τις 128 στο αρχείο `GAME.TXT`. Το `.TXT` μπαίνει όταν το όνομα δεν έχει τύπο.
- Με ομάδα (`A-H`, `A1-H1`, …) γράφει μόνο εκείνες τις 8.
- Το αρχείο είναι κείμενο, μία γραμμή για κάθε μεταβλητή:

  ```
  A=12
  B=0
  A1=-5
  ```

- `ΦΟΡΤΩΣΕ ΟΛΕΣ ΑΠΟ "GAME"` αλλάζει τις μεταβλητές που αναφέρει το αρχείο. Με ομάδα, αλλάζει μόνο όσες είναι και στην ομάδα. Γραμμές που δεν καταλαβαίνει τις αγνοεί, και αν το αρχείο λείπει δεν αλλάζει τίποτα.
- Έτσι ένα αρχείο μπορεί να επαναφέρει όλες τις μεταβλητές ή μόνο μία οκτάδα, π.χ. τις αποθηκευμένες θέσεις ενός παιχνιδιού.

## Τα κείμενα σε άλλες γλώσσες

Τα κείμενα ενός προγράμματος (παράθυρα, κουμπιά, TEXT, LABEL) μπορούν να έχουν μετάφραση σε κάθε γλώσσα του V-OS. Το πρόγραμμα τα δείχνει στη γλώσσα που είναι το V-OS όταν ξεκινά. Έτσι η CALC λέγεται «ΑΡΙΘΜΟΜΗΧΑΝΗ» στα ελληνικά, «CALCULATOR» στα αγγλικά, «CALCULATRICE» στα γαλλικά.

- **ΕΠΕΞΕΡΓΑΣΙΑ > ΓΛΩΣΣΑ ΚΕΙΜΕΝ. (^T):** περνά από τις γλώσσες EN, EL, FR, ES, DE, IT και ξανά στα κείμενα του ίδιου του προγράμματος. Κάτω από τα αντικείμενα, δίπλα στο όνομα, φαίνεται ο κωδικός της γλώσσας (π.χ. `CALC FR`).
- Σε μια γλώσσα, οι θέσεις κειμένου δείχνουν και αλλάζουν τα κείμενα σε αυτήν. Ένα κείμενο χωρίς μετάφραση δείχνει το δικό του, και όταν το αλλάξεις γίνεται η μετάφρασή του. Ένα νέο κείμενο που γράφεις σε μια γλώσσα γίνεται και το δικό του.
- Οι μεταφράσεις αποθηκεύονται μέσα στο `.VBS` (και στο `.VBN`), και τα έξι μαζί, περίπου 3K.
- Στο `.vbt` γράφονται με `LANG FR` και από κάτω γραμμές `"κείμενο" "μετάφραση"`.

## Αρχεία

- **`ΟΝΟΜΑ.VBS`:** το πρόγραμμα όπως το επεξεργάζεσαι. Το ανοίγει το ΑΝΟΙΓΜΑ, και ως 9K διαβάζονται.
- **`ΟΝΟΜΑ.VBN`:** το πρόγραμμα έτοιμο να τρέξει. Το γράφει η ΕΚΤΕΛΕΣΗ και ξεκινά και από τον Launcher. Είναι ο παίκτης (`VBRUN.SYS`) μαζί με το πρόγραμμα. Ο παίκτης μεταγλωττίζει τα blocks σε κώδικα Z80 όταν ξεκινά, οπότε τα προγράμματα τρέχουν γρήγορα.

Ένα `.VBS` φτιάχνεται και από κείμενο στον υπολογιστή, με το `tools/mkvbs.py`. Η σύνταξη περιγράφεται στην αρχή του αρχείου, και παραδείγματα είναι τα `blocks/examples/*.vbt` (CALC, MINES, FLAP, TICKER, VARS). Τα CALC και MINES έχουν και μεταφράσεις (`LANG`).

## Όρια

| | |
|---|---|
| Γραμμές (blocks) | 240 |
| Αντικείμενα | 6 |
| Scripts (`ΟΤΑΝ …`) | 16 |
| Μεταβλητές | 128 |
| ΕΠΑΝΑΛΑΒΕ σε ένα πρόγραμμα | 64 (από εκεί και πέρα μοιράζονται μετρητή) |
| Ανοιχτά blocks το ένα μέσα στο άλλο | 16 |
| Κείμενα | 32, ως 14 χαρακτήρες το καθένα, και σε 6 γλώσσες |
| Κοστούμια | 8, 16×16 |
| Κουμπιά | 64 |
| Κώδικας | τουλάχιστον 4.000 bytes και για το μεγαλύτερο πρόγραμμα. Ό,τι δεν χωρά αγνοείται |

## Συμβουλές

- **Scripts της σκηνής:** τα blocks κίνησης και εμφάνισης δεν κάνουν τίποτα, και τα X, Y, ΑΓΓΙΖΕΙ και ΣΤΗΝ ΑΚΡΗ δίνουν 0.
- **ΑΓΓΙΖΕΙ:** ισχύει μόνο όταν φαίνονται και τα δύο αντικείμενα.
- **Συγχρονισμός:** τα scripts τρέχουν «μαζί». Κάθε script παραχωρεί τη σειρά του στο τέλος κάθε επανάληψης και σε κάθε ΠΕΡΙΜΕΝΕ. Για να περιμένει ένα script κάποιο άλλο, χρησιμοποίησε μια μεταβλητή και `ΠΕΡΙΜΕΝΕ ΩΣ` (δες το MINES).
- **Έτοιμα παραδείγματα:** τα CALC, MINES, FLAP και TICKER ανοίγουν στο Studio (ΑΝΟΙΓΜΑ).
