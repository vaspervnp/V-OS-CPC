# 6. Blocks στον υπολογιστή: ο web editor και το `vbc.py`

Εκτός από το Studio, που τρέχει στον CPC, υπάρχει και ένας editor blocks για τον υπολογιστή. Η γλώσσα είναι η ίδια, με μερικά blocks παραπάνω: λίστες, θόρυβο, μέγεθος αντικειμένου, κείμενο με χρώμα.

## Ο editor

Άνοιξε το `blocks/editor.html` σε browser. Είναι βασισμένος στο Blockly και έχει ελληνικά ή αγγλικά.

- **Κατηγορίες:** γεγονότα, έλεγχος, κίνηση, εμφάνιση, κείμενο, τελεστές, αισθητήρες, μεταβλητές, λίστες και παράθυρα.
- **Αντικείμενα:** ορθογώνια ή κοστούμια. Ορίζονται σε πίνακα, και η σκηνή τα δείχνει με τα χρώματα του CPC. Σέρνονται με το ποντίκι.
- **Αρχεία:** ανοίγει και αποθηκεύει αρχεία `.vbp`. Είναι JSON με όλο το πρόγραμμα, οπότε γράφονται και με το χέρι.

## Μεταγλώττιση

```bash
python3 blocks/vbc.py pong.vbp --dsk build/vos.dsk
```

Το `vbc.py` γράφει το `build/ΟΝΟΜΑ.ASM`, με ένα σχόλιο για κάθε block. Το μεταγλωττίζει με τη RASM σε `ΟΝΟΜΑ.VBN`, με πίνακα relocation ώστε να τρέχει δίπλα σε άλλα προγράμματα, και με `--dsk` το βάζει στη δισκέτα.

| Επιλογή | Τι κάνει |
|---|---|
| `-o build` | φάκελος εξόδου |
| `--asm-only` | μόνο το `.ASM` |
| `--dsk build/vos.dsk` | και στη δισκέτα |

## Η μορφή `.vbp`

Η πλήρης περιγραφή είναι στην αρχή του `blocks/vbc.py`: γεγονότα, εντολές, τιμές, κοστούμια, εικονίδιο. Σε συντομία:

```json
{"name": "PONG", "mode": 0, "background": 0,
 "sprites": [{"name": "ball", "x": 90, "y": 100, "w": 6, "h": 6,
              "colour": 8, "vx": 2, "vy": 2, "visible": true}],
 "variables": {"score": 0},
 "scripts": [{"sprite": "ball", "when": {"event": "start"},
              "do": [{"block": "forever", "do": [{"block": "move"}, {"block": "bounce"}]}]}]}
```

- **Μεταβλητές και λίστες:** έχουν ονόματα, όχι γράμματα. Οι λίστες έχουν σταθερό μέγιστο μήκος.
- **Εικονίδιο:** το `"icon"` δίνει εικονίδιο για τον Launcher.
- **Πρόγραμμα με πολλά όμοια κομμάτια:** μπορεί να το γράψει ένα script σε Python. Δες το `tools/mkbricks.py`, που γράφει το `bricks.vbp` με 32 τούβλα.

## Παραδείγματα

Στο `blocks/examples/`:

| Αρχείο | Πρόγραμμα |
|---|---|
| `pong.vbp` | PONG |
| `catch.vbp` | CATCH |
| `starcat.vbp` | STARCAT: κοστούμια, μελωδία από λίστα |
| `counter.vbp` | COUNTER: παράθυρο και κουμπιά |
| `bricks.vbp` | BRICKS (το γράφει το `tools/mkbricks.py`) |

Τα `*.vbt` είναι προγράμματα του Studio σε κείμενο, για το `tools/mkvbs.py`. Βλ. [κεφάλαιο 5](05-studio.md).

| | Studio | web editor |
|---|---|---|
| Πού | στον CPC | στον υπολογιστή |
| Αρχείο | `.VBS` | `.vbp` |
| Μεταβλητές | 128, A–H15 | με ονόματα |

| SAVE/LOAD VARS | ναι | όχι |
