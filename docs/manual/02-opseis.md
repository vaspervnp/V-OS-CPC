# 2. Οι όψεις

Το V-OS έχει τέσσερις «όψεις», δηλαδή τρόπους να δεις τα αρχεία και τα προγράμματα, και τις ρυθμίσεις. Αλλάζεις όψη με τα F1–F4 ή από το μενού ΠΡΟΒΟΛΗ. Η κάθε όψη θυμάται ποιο αρχείο ήταν επιλεγμένο, και η επόμενη επιλέγει το ίδιο.

## Τα κοινά μενού

Τα δύο τελευταία μενού είναι ίδια σε όλες τις όψεις και στα προγράμματα:

| ΠΡΟΒΟΛΗ | | ΒΟΗΘΕΙΑ | |
|---|---|---|---|
| ΕΠΙΦΑΝΕΙΑ | F1 | ΠΛΗΚΤΡΑ | ^K |
| ΠΡΟΓΡΑΜΜΑΤΑ (Launcher) | F2 | ΣΧΕΤΙΚΑ ΜΕ ΤΟ V-OS | |
| COMMANDER | F3 | | |
| ΡΥΘΜΙΣΕΙΣ | F4 | | |
| ΠΡΟΓΡΑΜΜΑΤΑ (που τρέχουν) | F6 | | |
| ΑΛΛΑΓΗ ΓΛΩΣΣΑΣ | ^L | | |

Το ΒΟΗΘΕΙΑ > ΣΧΕΤΙΚΑ ΜΕ ΤΟ V-OS δείχνει την έκδοση (0.15 beta· κάθε milestone προσθέτει 0.01), την ημερομηνία κατασκευής, τον δημιουργό (Revive8bit, 2026) και τον αρχιτέκτονα (Vasper).

## Desktop (ΕΠΙΦΑΝΕΙΑ), F1

Mode 1. Ένα παράθυρο ΑΡΧΕΙΑ δείχνει τα αρχεία ενός drive ως εικονίδια, τέσσερα σε κάθε σειρά. Ο τύπος γράφεται μέσα στο εικονίδιο και το όνομα από κάτω, ενώ ένα `.VBN` έχει δίπλα ένα σημάδι «play». Δεξιά, δύο εικονίδια διαλέγουν το A: ή το B:. Στη γραμμή τίτλου φαίνονται η μορφή της δισκέτας και το πλήθος των αρχείων, και κάτω ο ελεύθερος χώρος.

| Πλήκτρο | Τι κάνει |
|---|---|
| βελάκια | επιλογή αρχείου (↑/↓ μία σειρά) |
| TAB | η επόμενη μονάδα: A:, B:, DISK (με κάρτα M4) |
| RETURN, ENTER | άνοιγμα: ένα πρόγραμμα τρέχει, ένα αρχείο γνωστού τύπου ανοίγει στο πρόγραμμά του, τα άλλα δείχνουν τα στοιχεία τους |
| ^C | αντιγραφή στην επόμενη μονάδα (από το DISK: στο A:) |
| ^D | διαγραφή (ρωτά πρώτα) |
| ^N | μετονομασία |
| ^R | ξαναδιάβασμα των δισκετών |
| ποντίκι | κλικ σε αρχείο: επιλογή, ξανά: άνοιγμα. Κλικ σε drive: το ανοίγει |

- **Μενού ΑΡΧΕΙΟ:** ΑΝΟΙΓΜΑ, ΣΤΟΙΧΕΙΑ ΑΡΧΕΙΟΥ (^I), ΑΝΤΙΓΡΑΦΗ ΣΤΗΝ ΕΠΟΜΕΝΗ, ΔΙΑΓΡΑΦΗ, ΜΕΤΟΝΟΜΑΣΙΑ, ΞΑΝΑΔΙΑΒΑΣΜΑ ΔΙΣΚΩΝ, ΕΞΟΔΟΣ ΣΤΗ BASIC.
- **Το παράθυρο ΑΡΧΕΙΑ** σέρνεται από τον τίτλο του και μένει εκεί, ακόμα κι όταν αλλάζεις όψη.
- **Άνοιγμα ανά τύπο** (και στον Commander): τα `.TXT` ανοίγουν στο NOTEPAD, τα `.MD` στο MARKDOWN, τα `.PIC` και `.LYR` στο PAINT, τα `.VDB` στο DATABASE, τα `.VSH` στο SHEET, τα `.MUS` στο MUSIC, που αρχίζει να τα παίζει. Το πρόγραμμα αναζητείται στη μονάδα του αρχείου, μετά στο A: και μετά στο B:. Αν δεν βρεθεί, βγαίνει «ΚΑΝΕΝΑ ΠΡΟΓΡΑΜΜΑ ΓΙΑ ΑΥΤΟ ΤΟ ΑΡΧΕΙΟ». Αν το πρόγραμμα έχει αλλαγές που δεν σώθηκαν, ρωτά πρώτα.

## Launcher (ΠΡΟΓΡΑΜΜΑΤΑ), F2

Mode 0, 16 χρώματα. Δείχνει μόνο τα προγράμματα μιας μονάδας (`.BIN`, `.VBN`, `.BAS`), στην αρχή του A:, ως πλακίδια σε πλέγμα 3×3, με τις επόμενες σελίδες από κάτω. Η γραμμή της σελίδας αρχίζει με τη μονάδα (`A:`, `B:`). Κάθε πρόγραμμα που έχει εικονίδιο το δείχνει στο πλακίδιό του. Το επιλεγμένο πλακίδιο είναι άσπρο.

| Πλήκτρο | Τι κάνει |
|---|---|
| βελάκια | επιλογή (↑/↓ μία σειρά. Μετά την άκρη, η επόμενη ή η προηγούμενη σελίδα) |
| RETURN, ENTER | τρέχει το πρόγραμμα. Αν τρέχει ήδη, συνεχίζει από εκεί που ήταν |
| ^A | το φορτώνει ως desk accessory (ΩΣ ΑΞΕΣΟΥΑΡ). Το F5 το ανοίγει μετά |
| ^R | ξαναδιάβασμα της δισκέτας |
| TAB | η επόμενη μονάδα (ΕΠΟΜΕΝΗ ΜΟΝΑΔΑ): A:, B:, DISK. Ένα πρόγραμμα που ξεκίνησε από το B: γυρίζει στο B: |
| ποντίκι | κλικ: επιλογή, ξανά: εκκίνηση |

**Μενού ΑΡΧΕΙΟ:** ΕΚΚΙΝΗΣΗ, ΩΣ ΑΞΕΣΟΥΑΡ, ΕΠΟΜΕΝΗ ΜΟΝΑΔΑ, ΞΑΝΑΔΙΑΒΑΣΜΑ ΔΙΣΚΩΝ, ΕΞΟΔΟΣ ΣΤΗ BASIC.

## Commander, F3

Mode 1, δύο πάνελ με λίστες αρχείων: αριστερά το A:, δεξιά το B:. Κάθε πάνελ δείχνει στον τίτλο του τη μορφή και το πλήθος των αρχείων, και κάτω τον ελεύθερο χώρο. Το ενεργό πάνελ έχει σκούρο τίτλο και επιλογή.

| Πλήκτρο | Τι κάνει |
|---|---|
| ↑/↓ | επιλογή (με SHIFT: μία σελίδα) |
| TAB, ←/→ | το άλλο πάνελ |
| RETURN, ENTER | άνοιγμα, όπως στο Desktop. Τα στοιχεία (μέγεθος, τύπος, διεύθυνση φόρτωσης, τα πρώτα bytes) με ^I |
| ^C | αντιγραφή στο άλλο πάνελ, οποιουδήποτε μεγέθους. Αν υπάρχει αρχείο με το ίδιο όνομα, ρωτά πρώτα |
| ^D | διαγραφή |
| ^N | μετονομασία |
| ^R | ξαναδιάβασμα και των δύο δισκετών |
| ^G | η επόμενη μονάδα για το ενεργό πάνελ: A:, B:, DISK (και με κλικ στον τίτλο του) |
| ποντίκι | κλικ: επιλογή, ξανά: άνοιγμα |

**Μενού ΑΡΧΕΙΟ:** ΑΝΟΙΓΜΑ, ΣΤΟΙΧΕΙΑ ΑΡΧΕΙΟΥ (^I), ΑΝΤΙΓΡΑΦΗ ΑΠΕΝΑΝΤΙ, ΔΙΑΓΡΑΦΗ, ΜΕΤΟΝΟΜΑΣΙΑ, ΞΑΝΑΔΙΑΒΑΣΜΑ ΔΙΣΚΩΝ, ΕΠΟΜΕΝΗ ΜΟΝΑΔΑ (^G), ΦΟΡΜΑΡΙΣΜΑ ΔΙΣΚΕΤΑΣ (DATA), ΕΞΟΔΟΣ ΣΤΗ BASIC.

> Το ΦΟΡΜΑΡΙΣΜΑ σβήνει όλα τα αρχεία της δισκέτας του ενεργού πάνελ. Ρωτά πρώτα.

## DISK: η κάρτα SD της M4

Με κάρτα M4, το Desktop έχει τρίτο εικονίδιο μονάδας, το DISK, κάτω από τα A: και B:, και το TAB πηγαίνει A: → B: → DISK. Φτάνουν σε αυτό και ο Launcher και τα πάνελ του Commander (^G). Ο τίτλος δείχνει τον φάκελο όπου βρίσκεσαι, π.χ. `DISK:/GAMES/`.

- **Οι φάκελοι** φαίνονται ως φάκελοι (εικονίδιο με καρτέλα, ή DIR στον Commander). Το RETURN σε έναν μπαίνει μέσα, και το `..`, η πρώτη γραμμή, βγαίνει προς τα πάνω. Στον Launcher υπάρχουν κι αυτοί, για να φτάνεις στα προγράμματα μέσα τους.
- **Όλα όπως σε δισκέτα:** τα προγράμματα τρέχουν από εκεί, τα αρχεία ανοίγουν στα προγράμματά τους, και τα ^C, ^D, ^N αντιγράφουν, σβήνουν και μετονομάζουν. Οι αντιγραφές ανάμεσα στο DISK και σε δισκέτα φτάνουν ως τα 16K. Φάκελοι και αρχεία έχουν ονόματα όπως στον CPC (8.3: `ΟΝΟΜΑ.EXT`). Τα μεγαλύτερα ονόματα δεν φαίνονται.
- **Το M4.SYS** (στη `vos.dsk`) φορτώνεται από το A: την πρώτη φορά που χρησιμοποιείται το DISK.
- **Όχι ακόμα:** το ΑΝΟΙΓΜΑ και η ΑΠΟΘΗΚΕΥΣΗ των προγραμμάτων (NOTEPAD, PAINT…) βλέπουν ακόμα μόνο τα A: και B:. Το DATABASE δουλεύει μόνο σε δισκέτες, και η κάρτα SD δεν φορμάρεται από το V-OS. Το ίδιο το V-OS ξεκινά ακόμα από δισκέτα στο A: (γράψε `|DISC` πριν από το `RUN"VOS"`: με κάρτα M4, ο CPC ξεκινά στην κάρτα SD).

## Setup (ΡΥΘΜΙΣΕΙΣ), F4

Mode 1. Μία γραμμή για κάθε ρύθμιση. Οι αλλαγές ισχύουν αμέσως. Με αποθήκευση (RETURN ή ^S) γράφονται στο `A:SETUP.CFG` και ισχύουν και στην επόμενη εκκίνηση.

| Ρύθμιση | Τιμές |
|---|---|
| ΟΨΗ ΕΚΚΙΝΗΣΗΣ | ΕΠΙΦΑΝΕΙΑ, ΠΡΟΓΡΑΜΜΑΤΑ, COMMANDER |
| ΓΛΩΣΣΑ | ENGLISH, ΕΛΛΗΝΙΚΑ, FRANÇAIS, ESPAÑOL, DEUTSCH, ITALIANO |
| ΚΑΘΥΣΤ. ΕΠΑΝΑΛΗΨΗΣ | πόσο κρατάς ένα πλήκτρο ώσπου να αρχίσει να επαναλαμβάνεται: ΣΥΝΤΟΜΗ, ΜΕΣΑΙΑ, ΜΕΓΑΛΗ |
| ΤΑΧΥΤ. ΕΠΑΝΑΛΗΨΗΣ | ΑΡΓΗ, ΜΕΣΑΙΑ, ΓΡΗΓΟΡΗ |
| ΠΟΝΤΙΚΙ AMX | ΝΑΙ, ΟΧΙ |
| ΑΝΑΓΝΩΣΗ AMX | ΣΤΑΘΜΕΣ (αρχικά) ή ΠΑΛΜΟΙ: πώς διαβάζεται το ποντίκι. Οι ΣΤΑΘΜΕΣ μετρούν κάθε ανάγνωση με κίνηση, οι ΠΑΛΜΟΙ μόνο τις αρχές των παλμών. Αν ο δείκτης κινείται πολύ γρήγορα ή πολύ αργά, δοκίμασε το άλλο |
| ΧΡΩΜΑ ΦΟΝΤΟΥ | ΜΠΛΕ, ΜΑΥΡΟ, ΠΡΑΣΙΝΟ, ΚΟΚΚΙΝΟ |
| ΠΛΗΚΤΡΟΛΟΓΙΑ | EN + ΓΛΩΣΣΑ, ΚΑΙ ΤΑ ΕΞΙ (ποια αλλάζει το CONTROL+SHIFT) |

| Πλήκτρο | Τι κάνει |
|---|---|
| ↑/↓ | επιλογή ρύθμισης |
| ←/→ | αλλαγή τιμής (και κλικ στη γραμμή) |
| RETURN, ^S | αποθήκευση |

Η αλλαγή ΓΛΩΣΣΑΣ φορτώνει αμέσως το pack της γλώσσας από το A:. Βλ. [κεφάλαιο 4](04-glosses.md).
