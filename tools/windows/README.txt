V-OS for Windows
================

Double-click V-OS.exe. It starts Caprice32 as an Amstrad CPC 6128 with
a 512K RAM expansion, with V-OS in drive A: and VROUVES in drive B:,
and V-OS starts by itself.

- Keys: the CPC's f1-f6, which V-OS uses for its views (f1 Desktop,
  f2 Launcher, f3 Commander), are the PC's numeric keypad 1-6. COPY
  is the left Alt. The PC's F1 opens Caprice32's own menu (reset,
  discs, options), F10 quits.
- VROUVES, all seven stages: in V-OS, keypad 3 (the Commander), TAB
  (drive B:), then ESC, FILE > RUN on VROUVES.BIN. The V-OS disc has
  stage 1 in the Launcher (keypad 2).
- The discs are disks\vos.dsk and disks\vrouves.dsk; V-OS saves to
  them. Keep a copy if you want to start afresh.

Caprice32 (caprice32\, GPL, see caprice32\COPYING.txt) comes from
https://github.com/ColinPitrat/caprice32. V-OS: the V-OS-CPC project.
